# Discord Mappings

An attempt at creating mappings for the `discord_web` client, and possibily others too!
I'm trying to make mappings for each chunk and its name, module path, variables names, etc.

This project does not provide the decompiled results, to prevent a dmca. instead you have to download discord chunks files into a folder named `chunks`, and run `map.js`.

## Paths

The paths are the official one, taken from the android app.
